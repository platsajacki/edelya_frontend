# Название товара и ввод количества

## Где проблема

Экран списка покупок → строка товара: `src/pages/ShoppingListDetailPage.vue` использует `src/components/ShoppingListItemRow.vue`. Когда пользователь нажимает на количество, вместо числа появляется поле ввода. Его собственная ширина раздвигает блок `− / ввод / +`, а у блока стоит `flex-shrink: 0`. Название сжимается до узкой колонки и переносится по одной букве, как на скриншоте.

Предложение решения. **Перенос вниз — ваш вариант.** Если названию тесно, размещать `− / ввод / +` на отдельной последней строке с выравниванием вправо. Переход между расположениями сделать плавным; сам блок можно немного уменьшить, сохранив удобные для нажатия кнопки.
